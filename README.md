# 소개팅 매칭 로직

바이브코딩 실습 4 — **가장 잘 맞는 상대를 찾아줍니다.**
소개팅 앱이 아니라 *매칭 로직*을 만드는 과제입니다. 추천 상대와, 그 상대를 고른 내 로직이 화면에 나옵니다.

## 실행

설치할 것 없이 `index.html`을 브라우저로 열면 됩니다. (파일 4개가 같은 폴더에 있어야 해요)
입력한 데이터는 브라우저(localStorage)에만 저장됩니다.

## 흐름

1. **올린다** — 내 프로필(나이·키·지역·종교·흡연·음주·외모·연봉·MBTI·관심사) + 성향 질문 10개.
   가상 프로필 24명이 들어 있고, 친구 프로필은 오른쪽 위 버튼으로 **별도 창**(`friend.html`)에서 대신 올립니다.
2. **내 로직을 만든다**
   - ① 거르기: 성별, 나이 범위, 최소 키, 흡연자 제외, 같은 종교만, 나 자신 제외
   - ② 점수표: 관심사·나이·키·외모·지역·종교·음주·연봉·주선자 추천 + MBTI 궁합표 + 연애 성향 4가지 (모든 숫자 수정 가능)
   - ③ 이유: 1위가 왜 1위인지, 2위와의 결정적 차이, 동점 규칙
3. **추천하고, 보여준다** — 1위와 이유, 전체 순위와 항목별 점수, 제외된 사람과 걸린 조건, 0명일 때 안내

## 소개팅 앱 방식 적용

- **쌍방 매칭** — 내가 상대를 보는 점수 × 상대가 나를 보는 점수의 기하평균 = "서로 맞는 정도"
- **오늘의 소개** — 한 명씩 카드로 ♥ 좋아요 / ✕ 패스 (키보드 ← →). 상대 점수가 기준 이상이면 매칭 성사
- **대화 시작 질문** — 매칭 성사 시 겹치는 관심사·성향·MBTI로 첫 마디 추천 (복사 버튼)
- **주선자 한마디** — 친구를 대신 올릴 때 남긴 추천이 카드에 보이고 점수에 반영

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 메인 화면 (매칭 로직, 결과, 오늘의 소개) |
| `friend.html` | 친구 프로필 등록 창 |
| `common.js` | 공통 데이터·질문·MBTI 궁합표·폼 |
| `common.css` | 공통 스타일 |

> MBTI 궁합표는 국내 커뮤니티에서 널리 공유되는 표(원본 출처 불명)를 옮긴 재미용 기준입니다.
